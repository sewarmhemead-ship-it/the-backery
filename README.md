# the.bakery — موقع المنيو

موقع منيو لمحل **the.bakery** بـ Designer Outlet Salzburg.
مبني للموبايل أول شي، لأنه الزبون بيفتحه من QR وهو واقف بالطابور.

بثلاث لغات: ألماني (الافتراضي)، إنجليزي، وعربي مع دعم الكتابة من اليمين لليسار.

---

## شو في بالمجلدات

| المجلد | شو فيه |
|---|---|
| `site/` | **الموقع نفسه.** هاد اللي بترفعه |
| `brand/` | اللوجو الأصلي، ملف الشاشات، وملف حقائق الماركة |
| `tools/` | سكربتات مساعدة (الـQR واللقطات) |
| `qr/` | الـQR وكرت الطاولة، بيتولّدوا بأمر |
| `shots/` | لقطات شاشة للمراجعة |

## كيف تعدّل المنيو

افتح ملف واحد بس:

```
site/assets/js/menu-data.js
```

جوّاته شرح كامل بالعربي. الأساسيات:

- **تضيف صنف:** انسخ بلوك من `{` لـ `}` وبدّل الاسم والسعر والوصف
- **تحط سعر:** `price: 4.20` بالنقطة مش الفاصلة. الموقع بيحوّلها لـ `4,20 €` لحاله
- **سعر لسا مش جاهز:** `price: null` والموقع بيكتب «على الطلب» بدل ما يبيّن خربان
- **صنف جديد:** حطلو `tags: ["new"]` وبيطلع تلقائياً بقسم «الجديد عنّا» فوق
- **قسم فاضي:** بينخفى لحاله، ما بتحتاج تعمل إشي

بعد ما تعدّل، احفظ وارفع الملف. خلص.

النصوص الثابتة (العناوين، الأزرار، الدوام) موجودة بـ `site/assets/js/i18n.js`.

## كيف ترفع الموقع

### أسهل طريقة، سحب وإفلات

1. روح على [app.netlify.com/drop](https://app.netlify.com/drop)
2. اسحب مجلد **`site`** كامل وارميه بالصفحة
3. بعد ثواني بيعطيك رابط

الرابط الأول بيكون عشوائي. من `Site settings > Change site name` بتغيّره لشي زي
`the-bakery-salzburg`.

### لما تعدّل المنيو لاحقاً

ارجع لنفس الصفحة واسحب المجلد مرة تانية، بيتحدّث فوراً.

## كيف تطلّع الـQR

بعد ما يصير عندك الرابط النهائي:

```bash
python tools/make-qr.py https://the-bakery-salzburg.netlify.app
```

بيطلع بمجلد `qr/`:

| الملف | لوين |
|---|---|
| `menu-qr.svg` | للطباعة. بيكبر لأي حجم بدون ما يبهت |
| `menu-qr.png` | للسوشال والشاشات |
| `tent-card.svg` | كرت طاولة A6 جاهز للطباعة |

الكود مولّد بأعلى مستوى تصحيح خطأ (H)، يعني بيضل يشتغل حتى لو 30% منه
متوسّخ أو مخربش. مهم لأنه بينحط عالطاولة.

> **مهم:** كل ما تغيّر الرابط لازم تطبع QR جديد. فاختار اسم الموقع
> وثبّت عليه قبل ما تطبع.

### لينك بلغة محددة

بتقدر تعمل QR يفتح بلغة معيّنة على طول:

```
https://your-site.netlify.app/?lang=ar
https://your-site.netlify.app/?lang=en
```

مفيد إذا حابب كرت منفصل للسيّاح.

## للمطوّرين

ما في build ولا `npm install`. HTML و CSS و JS عادي.

```bash
# تشغيل محلي
python -m http.server 4321 --directory site

# لقطات شاشة للمراجعة
python tools/shoot.py
```

المكتبات (GSAP و Lenis) بتيجي من CDN.

### الهوية

الألوان والخطوط كلها مسحوبة من ملفات شاشات المحل الرسمية، مش مخترعة.
التفاصيل بـ [`brand/brand-facts.md`](brand/brand-facts.md).

| | |
|---|---|
| كحلي | `#000045` |
| زهري | `#F1C2CC` |
| سماوي | `#BFE4ED` |
| نبيذي | `#730E23` |
| ذهبي | `#C9762B` |

كل قسم بالموقع إله لون خلفية خاص، والشريط العلوي بياخد نفس اللون وهو نازل.
نفس فكرة شاشات LCD اللي بالمحل.

## الموقع الجديد (`site-v2/`)

نسخة جديدة كاملة للموقع، مبنية على الهوية الرسمية: خط **Changa** للشعار، **Open Sans Condensed** للسطور، ونبيذي `#730F23` على سماوي `#C0E4ED`.

- كل قسم إله لون، وصفحة الموقع كلها بتغيّر لونها وانت نازل، متل شاشات المحل
- الست اللي باللوغو بتمشي تحت الشاشة وانت عم تنزل، برجلين بيتحركوا
- ألماني وإنجليزي وعربي

الأسعار والأصناف موجودة بـ `site-v2/index.html`، والنصوص بـ `site-v2/assets/js/i18n.js`.

تشغيل محلي:

```bash
python -m http.server 4322 --directory site-v2
```

للرفع على Netlify اسحب مجلد **`site-v2`** بدل `site`.
